1. What is a Biological Database?

A biological database is an organized collection of biological information stored digitally.

Think:

Library
=
Books

Biological Database
=
Biological Information

Contains:

DNA sequences
RNA sequences
Protein sequences
Structures
Research papers
Annotations
2. Why Do We Need Databases?

Modern biology generates huge amounts of data.

Example:

Human Genome
≈ 3 billion base pairs

Impossible to manage manually.

Databases help scientists:

Store data
Search data
Share data
Analyze data

Full Form:

Reference Sequence Database

Managed by NCBI.

Contains:

High-quality curated sequences

Difference:

GenBank
=

=

7. EMBL

Full Form:

European Molecular Biology Laboratory Database

European sequence repository.

Stores:

DNA
RNA
Protein data
8. DDBJ

Full Form:

DNA Data Bank of Japan

Japanese sequence database.

Important Fact

These databases exchange data daily.

GenBank
↔
EMBL
↔
DDBJ

So they contain almost identical sequence collections.

12. Accession Number

Every database entry receives a unique ID.

Example:

NM_007294

Think:

Roll Number of a sequence
Why Important?

Allows exact retrieval.

Instead of searching:

BRCA1

search:

NM_007294

More accurate.
